# Bulk operations

XLocality has two different ways to generate or move a lot of translations at once — they solve different problems.

## Bulk translate a locale

Use this when a locale is missing translations for a batch of keys and you want to generate all (or some) of them in one go — for example, right after adding a new locale to an existing project with hundreds of keys.

From **Locales**, click **Bulk translate** on the locale's row. This opens a preview showing every key that's missing a translation (or only has a failed one) for that locale, with a checkbox next to each — all are selected by default. Review the count, deselect anything you don't want translated yet, and confirm.

<!-- screenshot: bulk translate modal with candidate list and cost warning -->

::: warning
This calls your configured LLM provider once per selected key, which can take a while and cost real money for large selections — the modal shows exactly how many translations will be generated before you confirm.
:::

## Import

Use this when you already have translated text from somewhere else — a spreadsheet, another tool's export, a professional translator's deliverable — and want to load it in directly rather than having the LLM generate it. Import is available for [Translations](/guide/translations), [Locales](/guide/locales), and [Context Tags](/guide/context-tags), each with the same CSV/JSON upsert pattern: re-importing an unmodified export changes nothing, and protected rows (locked translations, system locales) are skipped rather than overwritten.

## Which one do I want?

| | Bulk translate | Import |
|---|---|---|
| Source of the text | Generated by your LLM provider | Comes from your file |
| Cost | Uses LLM credits | Free |
| Typical use | New locale, mostly-empty project | Migrating existing translations, professional translation |

## Export

Every resource that supports import also supports export, in the same format — useful for backups, moving data between environments, or handing a project's content to a translator to review offline.
